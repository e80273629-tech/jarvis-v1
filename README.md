# OSVYRA — Inteligência Artificial

Protótipo web instalável (PWA), pensado primeiro para Android.

## O que funciona nesta versão
- Painel inicial com quatro módulos.
- Estúdio de imagens: cria uma arte promocional vetorial no próprio navegador e exporta PNG.
- Estúdio de vídeos: gera uma estrutura simples de roteiro.
- Central comercial: salva oportunidades localmente no navegador.
- Interface responsiva para celular.

## O que ainda não está conectado
- Nenhuma API de IA externa.
- Nenhum gerador de vídeo.
- Nenhum acesso ao Canva.
- Nenhum controle irrestrito do Android.
- Nenhum envio de mensagens ou publicação.
- Os dados de leads ficam no armazenamento local do navegador; limpar os dados do navegador pode apagá-los.

## Como testar no Android
1. Envie os arquivos para um repositório novo no GitHub.
2. Ative GitHub Pages em Settings > Pages > Deploy from a branch > main > /(root).
3. Abra o endereço publicado no Chrome do Android.
4. Use o menu do Chrome > Adicionar à tela inicial.
